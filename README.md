# عيادتي (Eyadati) - نظام إدارة عيادات ومراكز طب الأسنان

نظام **عيادتي** هو تطبيق سطح مكتب متكامل مصمم خصيصاً لإدارة عيادات ومراكز طب الأسنان على نظام التشغيل Windows. يعمل النظام وفق معمارية محلية أولاً (Offline-First)، مما يضمن استمرارية العمل والسرعة الفائقة وحماية خصوصية بيانات المرضى والملفات السريرية دون الحاجة إلى اتصال دائم بالإنترنت.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **بيئة سطح المكتب**: Electron 31
- **واجهة المستخدم**: React 18.3 + Vite 5 + TailwindCSS (RTL كامل من اليمين لليسار)
- **لغة البرمجة**: TypeScript (Strict Mode)
- **قاعدة البيانات المحلية**: SQLite3 فائقة الأداء عبر `better-sqlite3` المدمجة محلياً
- **إدارة المخطط والبيانات**: Drizzle ORM + Drizzle Kit
- **التحقق والأمان**: Zod Schema Validation لجميع قنوات IPC
- **إدارة الحالة والبيانات**: TanStack Query (React Query) v5 + Zustand
- **الفوترة والامتثال**: دعم متطلبات الفاتورة الضريبية المبسطة وهيئة الزكاة والضريبة والجمارك (ZATCA QR)

---

## 📋 المتطلبات الأساسية (Prerequisites)

1. **نظام التشغيل**: Windows 10 أو Windows 11 (معمارية x64).
2. **Node.js**: الإصدار `v20.x` أو أحدث (موصى به `Node.js 20.18 LTS`).
3. **أدوات تجميع C++ على Windows**:
   - يلزم وجود **Visual Studio Build Tools 2022** لبناء وحدة `better-sqlite3` الأصلية المتوافقة مع Electron.
   - يجب تضمين حزمة العمل **"تطوير تطبيقات سطح المكتب بلغة C++" (Desktop development with C++)** مع **Windows 10/11 SDK**.

## 🚀 التثبيت والتهيئة (Installation)

قم باستنساخ المشروع وتثبيت الحزم:

```bash
npm install
```

> **ملاحظة حول postinstall:** يقوم السكربت التلقائي `scripts/postinstall.js` بمحاولة إعادة تجميع `better-sqlite3` لـ Electron. في حال عدم توفر أدوات C++ على جهاز التطوير، سينتهي التثبيت بسلام مع طباعة إرشادات واضحة، مما يتيح لك تطوير واجهة المستخدم عبر المتصفح دون انقطاع.

## 💻 سكربتات التشغيل والتطوير (Scripts)

| الأمر | الوصف |
| :--- | :--- |
| `npm run dev:desktop` | تشغيل التطبيق في وضع سطح المكتب الكامل (Vite + نافذة Electron بالتوازي). |
| `npm run dev:vite` | تشغيل خادم تطوير واجهة المستخدم السريعة عبر المتصفح (`http://localhost:3000`). |

| `npm run build` | تجميع كود الواجهة الأمامية (Vite) وملفات Electron (Main + Preload). |

| `npm run lint` | فحص سلامة الأنواع الصارمة في TypeScript (`tsc --noEmit`). |
| `npm test` | تشغيل حزمة الاختبارات الآلية الشاملة (64 اختباراً عبر 12 حزمة اختبار). |

## 🧙‍♂️ سلوك أول تشغيل (معالج الإعداد الأولي - Setup Wizard)

عند تثبيت وتشغيل البرنامج لأول مرة على جهاز العيادة:
1. يكتشف النظام عدم وجود أي بيانات سابقة أو مستخدم مدير في قاعدة البيانات المحلية.
2. يوجه التطبيق المستخدم تلقائياً وبشكل إلزامي إلى **معالج الإعداد الأولي** (`/setup`).
3. يقوم المستخدم بضبط:
   - **بيانات المنشأة**: اسم العيادة، الشعار، الرقم الضريبي (ZATCA)، العنوان، ورقم الهاتف.
   - **حساب المدير العام**: الاسم، اسم المستخدم، وكلمة المرور المشفرة بخوارزمية Bcrypt.
   - **ساعات العمل والعملة**: تحديد أوقات العمل الرسمية وفترات المواعيد.
4. فور إتمام المعالج، يتم تفعيل النظام وحفظ الإعدادات في قاعدة البيانات، ويُغلق المعالج نهائياً ليتم التوجيه لشاشة تسجيل الدخول الرسمية.

## 🔐 نظام التراخيص الرقمية (Licensing System)

يعتمد نظام التراخيص في "عيادتي" على التوقيع الرقمي غير المتماثل (Ed25519) و HMAC-SHA256 مع بصمة الجهاز (Hardware Fingerprint)، مما يتيح التحقق الصارم من التراخيص دون الحاجة لاتصال مستمر بالإنترنت:

- **توليد زوج مفاتيح التوقيع**:
  ```bash
  npm run license:gen-keys
  ```
  *(يُحفظ المفتاح الخاص `private.key` في مكان سري لدى الشركة ولا يُضمن في تطبيق العميل مطلقا).*
- **إصدار ترخيص جديد**:
  ```bash
  npm run license:issue -- --clinic "عيادة النخبة" --plan professional --days 365 --seats 3
  ```
- **فحص وتحليل رمز ترخيص**:
  ```bash
  npm run license:inspect -- --token "<LICENSE_TOKEN>"
  ```
